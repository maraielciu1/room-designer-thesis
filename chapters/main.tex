ABSTRACT
\vspace{0.5cm}	
\hrule
\vspace{0.5cm}	

Interior design decisions are difficult to evaluate without spatially accurate visualisation of furniture and finishes in a real environment. Existing augmented reality solutions treat the room as a transiently detected floor plane, provide no persistent room model, and require the user to be physically present in the space for every design iteration. The result is a tool suited to a single in-store moment, not to the extended iterative process that characterises real interior redesign. This thesis addresses these limitations through six engineering contributions.

The primary contribution is a unified scan-to-edit pipeline for iOS that connects Apple's RoomPlan API, which produces a metric, semantically annotated digital twin of a room, to a RealityKit-based editor in which detected furniture instances can be replaced with virtual USDZ assets via gesture-based manipulation, with state persisted across sessions. The second is the integration of Object Capture for on-device photogrammetric asset authoring, eliminating any dependency on external tooling. The third is a Metal-based Gaussian splat renderer and SHARP client for interactive viewing of 3D Gaussian Splatting scenes and direct comparison with mesh-based representations. The fourth is a reference SwiftUI/MVVM architecture that keeps room metadata responsive while storing heavy scan payloads on disk. The fifth is a virtual decor extension covering wall art, carpet, and dynamic lighting within the same editor workflow. The sixth is a DCC export service: completed room designs can be exported as a shareable ZIP archive containing a glTF scene, USDZ furniture copies, JSON placement manifests, and a Blender Python helper script for further editing in desktop tools.


The thesis is structured in seven chapters, moving from related work and theoretical grounding through requirements, implementation, evaluation, and conclusions.
